Project Background

项目背景

在以英文或其他外语为主的出行环境中，许多中老年人面临的并不只是"不会外语"，而是三重叠加的真实困难

📱

不会使用复杂 App

传统翻译软件界面复杂、操作步骤多，对中老年人来说是难以跨越的技术门槛

😰

紧张情境难以表达

在异国他乡的陌生环境中，即使会说中文，也可能因紧张而表达不清需求

🗣️

口语化表达难翻译

零散的口语、不完整的句子，传统翻译工具难以准确理解和转换

Project Value

项目价值

从"翻译工具"到"表达代理"的产品级重构

零门槛表达

用户无需思考外语表达、无需打字、无需理解翻译逻辑，只需用中文自然说出自己的需求。系统将口语化、零散甚至混乱的中文，自动整理为清晰、礼貌、易理解的标准表达。

双向沟通

不仅能把您的话翻译成外语，还能听懂对方的回答并用中文播报。真正实现"您用中文说，我替您说给对方听；对方说外语，我帮您听懂"。

极致简化

砍掉所有的视觉噪音，只为极致的速度与确定感而设计。降低操作门槛、减少交互步骤、消除长辈独自面对陌生世界的心理恐惧，是我们的最高优先级。

温暖陪伴

产品语言避免强调"翻译"，更多使用"替您说""帮您表达""帮您听懂"。让用户感受到的是"有人在帮我沟通"，而不是"我要操作一个工具"。

与联合国可持续发展目标（SDGs）高度契合

有助于减少不平等（SDG 10），让语言与技术能力较弱的人群平等参与社会活动；支持良好健康与福祉（SDG 3），在医疗与紧急场景中保障有效沟通；促进可持续城市和社区（SDG 11），使老龄人群能够更安全、自主地进行跨地区与跨国家流动。

Product Introduction

您的口袋翻译官

「我在」不是传统翻译软件，而是一个"语音代说助手"。它要解决的不是"把一句话翻译成另一种语言"这么简单，而是帮助不熟悉外语、不擅长操作手机的长辈，在国外可以更安心地开口、求助、问路、购物和办理事务。

我们深知出境旅行时的不安与焦虑，特别是面对语言障碍时的无助。因此，「我在」采用最直观的交互设计，让您无需学习即可上手，真正实现"随时随地，我一直都在"的承诺。

✓ 大字号、高对比、清晰边界设计
✓ 单核心操作入口，一屏完成任务
✓ 关键状态持续反馈，消除不确定感
✓ 按钮文案口语化，零学习成本

Features

产品功能

四大核心能力，覆盖出行全场景

按住说话，即刻翻译

点击首页大圆按钮，直接说出您的需求。手机会实时监听您的语音，将口语化的中文自动整理为标准表达，无需您思考如何组织语言。

  • 实时语音识别，边说边显示
  • 自动语义补全，整理为标准表达
  • 无需打字，降低操作门槛
  • 识别失败时提供友好提示和兜底方案

大字展示，替您说给对方听

系统将您的话翻译成目标语言，以大字体展示在屏幕上，方便对方阅读。同时自动语音播放，让对方既能看又能听，确保沟通无障碍。

  • 超大字体展示翻译结果
  • 自动语音播报，音量清晰
  • 支持"再播放一次"重复播报
  • 可查看原句，对比理解

听对方说话，帮您理解

在结果页点击"对方说话，我帮您听"，进入反向沟通模式。系统会听对方说的外语，并整理成中文展示，同时支持中文语音播报，实现真正的双向交流。

  • 识别对方外语并翻译成中文
  • 中文语音播报，让您听懂回复
  • 支持多轮对话，持续沟通
  • 可查看外语原句，确认理解

紧急求助，一键即达

底部功能栏的"紧急求助"按钮，预设了四种常见紧急场景：迷路、身体不适、需要帮助、物品丢失。点击即可立即发送求救信息，关键时刻为您争取宝贵时间。

  • 我迷路了 — 请帮我联系家人
  • 身体不适 — 需要看医生
  • 需要帮助 — 请帮我报警
  • 物品丢失 — 请帮我寻找
