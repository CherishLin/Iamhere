# 我在 - 智能语音代说助手

> 🌍 随时随地，我一直都在。
>
> *—— 给父母的出国旅行礼物*

---

## 💝 产品理念

**"我在"** 是子女为父母准备的贴心礼物。

当父母独自出国旅行时，语言障碍往往让他们感到不安。普通翻译App操作复杂、需要打字、场景繁多，对中老年用户并不友好。

**"我在"只做一件事**：
> 父母按住按钮，用中文说出需求，我们帮TA翻译成外语并大声"说"出来。

**无需打字、无需选择场景、无需输入外语** —— 就像子女始终陪在身边。

## 🚀 使用场景

### 🆘 紧急情况（一键求助）
- 🗺️ **我迷路了** - "我迷路了，请帮我联系我的家人"
- 🏥 **身体不适** - "我身体不适，需要看医生"
- 🚔 **需要帮助** - "请帮我报警，我需要帮助"
- 🎒 **物品丢失** - "我的东西丢了，请帮我找找"

- 🚕 **打车出行** - "请带我去机场"

- 🏨 **酒店入住** - "我想办理入住手续"

## 🔌 生产环境优化

当前版本使用浏览器内置的 Web Speech API 进行语音识别，使用模板翻译进行演示。

### 推荐接入翻译API

#### Claude API（推荐）
```javascript
const response = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'x-api-key': 'your-api-key'
    },
    body: JSON.stringify({
        model: 'claude-sonnet-4-6',
        system: '你是中老年旅行者的语音助手。将中文转为标准礼貌的表达，再翻译为目标语言。',
        messages: [{ role: 'user', content: text }]
    })
});
```

## 🎁 送给父母的设置指南

### 子女可提前完成：

1. **预设目标语言**
   - 点击底部 🌍 按钮
   - 选择父母将要前往的国家语言

2. **测试自动语音**
   - 点击底部 🔊 按钮
   - 确保"自动语音已开启"

3. **演示紧急求助**
   - 点击底部 🆘 按钮
   - 向父母展示四个紧急场景

4. **教会基础操作**
   - "按住大圆按钮说话"
   - "说完松开，等它翻译"
   - "给对方看屏幕上的大字"
